\## Program Descriptions



\### Unit 3: Polymorphism



\#### 1. CAD Shape Drawing System (`1\_CAD\_Shape\_Drawing\_System.cpp`)

\- \*\*Description:\*\* Demonstrates runtime polymorphism (dynamic binding) using an abstract base class `Shape` with pure virtual functions `area()` and `draw()`. Derived shapes (`Circle`, `Rectangle`) override these methods to calculate dimensions and render geometry.



\#### 2. Complex Number Calculator (`2\_Complex\_Number\_Calculator.cpp`)

\- \*\*Description:\*\* Demonstrates compile-time polymorphism through operator overloading. Overloads standard operators (`+`, `-`, `\*`, `==`) for a `Complex` class to enable clean arithmetic and comparison syntax.



\#### 3. Input Validation Service (`3\_Input\_Validation\_Service.cpp`)

\- \*\*Description:\*\* Demonstrates compile-time polymorphism via function overloading. Provides overloaded `validate()` member functions to validate various data types including student marks, monetary values, and string formats.



\#### 4. Media Player with Polymorphic Controls (`Project\_Media\_Player\_with\_Polymorphic\_Controls.cpp`)

\- \*\*Description:\*\* A mini-project showcasing dynamic polymorphism and interface design. A base class `Media` defines playback contracts (`play()`, `pause()`, `stop()`), implemented polymorphically across `Audio` and `Video` streams within a playlist manager.
