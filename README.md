## 🚀 Scenario-Based Implementations & Mini Projects

### 📌 Unit 1: Fundamentals of OOP
- **Focus:** Classes, objects, data encapsulation, access specifiers (`public`/`private`/`protected`), constructor overloads, destructors, static data members, and static methods.
- **Programs:**
  1. `1_Smart_Agriculture_Sensor_Monitor.cpp` — IoT moisture monitoring simulation with real-time updates.
  2. `2_Student_Attendance_Management_System.cpp` — Academic tracker calculating percentage and compliance.
  3. `3_E_Commerce_Product_Catalog.cpp` — Inventory catalog tracking active instances via static members.
  4. `Project_Smart_Home_Device_Manager.cpp` *(Mini Project)* — Multi-room smart device controller.

---

### 📌 Unit 2: Inheritance
- **Focus:** Single, multilevel, hierarchical, and multiple inheritance, scope resolution, constructor delegation, order of construction/destruction, protected access, and virtual base classes (diamond inheritance resolution).
- **Programs:**
  1. `1_Employee_Payroll_System.cpp` — Full-time and part-time employee hierarchy with polymorphic salary calculations.
  2. `2_Digital_Payment_Gateway.cpp` — Credit card and UPI transaction processing via base abstraction.
  3. `3_Vehicle_Fleet_Management.cpp` — Logistics fleet modeling vehicle specs and cargo hauling.
  4. `Project_Banking_System_with_Account_Hierarchy.cpp` *(Mini Project)* — Savings and Current accounts with transaction ledger, overdraft rules, and interest computation.

---

### 📌 Unit 3: Polymorphism
- **Focus:** Compile-time polymorphism (function overloading, unary and binary operator overloading, friend operators), and Run-time polymorphism (virtual functions, pure virtual functions, abstract base classes, vtables, virtual destructors, and object slicing prevention).
- **Programs:**
  1. `1_CAD_Shape_Drawing_System.cpp` — 2D vector geometry rendering engine with dynamic binding.
  2. `2_Complex_Number_Calculator.cpp` — Algebraic arithmetic overloads (`+`, `-`, `*`, `==`) for complex numbers.
  3. `3_Input_Validation_Service.cpp` — Overloaded validation service across disparate enterprise inputs.
  4. `Project_Media_Player_with_Polymorphic_Controls.cpp` *(Mini Project)* — Media player controlling heterogeneous audio/video playlist streams.

---

### 📌 Unit 4: Files and Streams
- **Focus:** Text file processing (`ifstream`, `ofstream`, `fstream`), formatted file I/O, CSV serialization, binary I/O (`read()`, `write()`, `reinterpret_cast`), file pointers (`seekg()`, `seekp()`, `tellg()`, `tellp()`), random access, and stream error handling (`good()`, `eof()`, `fail()`, `bad()`).
- **Programs:**
  1. `1_Student_Record_File_System.cpp` — Persistent CSV text-based student database with line parsing.
  2. `2_Server_Log_Analyzer.cpp` — Production server log processor extracting security and error incidents.
  3. `3_Binary_File_for_Fixed_Size_Records.cpp` — High-performance binary metadata serialization.
  4. `Project_Library_Book_Management_System.cpp` *(Mini Project)* — Full CRUD library book database with file persistence and issue/return state management.

## ⚙️ Compilation & Execution

### Prerequisites
- A modern C++ compiler supporting **C++17** or later (`g++`, `clang++`, or MSVC).
- Git for version control.

### Compilation Command

#### Using GCC / Clang (Linux / macOS / Git Bash):
```bash
# Compile any program (example: Unit 1 Scenario 1)
g++ -std=c++17 "Unit_1_Fundamentals/1_Smart_Agriculture_Sensor_Monitor.cpp" -o program
./program

# Compile any Code Book program (example: Unit 2 Program 1)
g++ -std=c++17 "Unit 2 Code Book/Program 1.cpp" -o program
./program
```

#### Windows with MinGW:
```cmd
g++ -std=c++17 "Unit 4 Code Book\Program 15.cpp" -o program.exe
program.exe
```

## 💡 Key OOP Concepts Demonstrated

- **Encapsulation & Data Hiding:** Member variables kept private/protected with controlled accessors and mutators.
- **Inheritance & Code Reusability:** Deriving specialized classes while maintaining clean object lifecycle orders.
- **Virtual Base Classes & Diamond Problem:** Avoiding multiple inheritance duplicates using `virtual public`.
- **Compile-Time Polymorphism:** Static binding via overloaded functions and intuitive operator overloads.
- **Run-Time Polymorphism:** Dynamic binding through `virtual` and `override` dispatch with `std::unique_ptr` polymorphic containers.
- **File Persistence:** Complete transactional file workflows using both text CSV formats and direct binary memory blocks.
