\## Program Descriptions



\### Unit 2: Inheritance



\#### 1. Employee Payroll System (`1\_Employee\_Payroll\_System.cpp`)

\- \*\*Description:\*\* Implements an inheritance hierarchy with an abstract base class `Employee` and derived classes `FullTimeEmployee` and `PartTimeEmployee`. Uses pure virtual methods to calculate compensation depending on contract and employment types.



\#### 2. Digital Payment Gateway (`2\_Digital\_Payment\_Gateway.cpp`)

\- \*\*Description:\*\* Demonstrates abstraction and hierarchical inheritance via a base `PaymentMethod` class. Provides concrete implementations for `CreditCardPayment` and `UPIPayment` to process and verify electronic transactions.



\#### 3. Vehicle Fleet Management (`3\_Vehicle\_Fleet\_Management.cpp`)

\- \*\*Description:\*\* Uses inheritance to manage a transportation fleet. Base class `Vehicle` tracks registration, engine state, and fuel levels, while specialized derived classes (e.g., `Truck`) extend functionality with cargo capacity metrics.



\#### 4. Banking System with Account Hierarchy (`Project\_Banking\_System\_with\_Account\_Hierarchy.cpp`)

\- \*\*Description:\*\* A mini-project implementing an account hierarchy with base class `Account` and specialized derived classes (`SavingsAccount`, `CurrentAccount`). Manages deposits, withdrawals, interest computations, overdraft limits, and transaction validations.
