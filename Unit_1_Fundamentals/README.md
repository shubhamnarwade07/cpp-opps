\## Program Descriptions



\### Unit 1: Fundamentals



\#### 1. Smart Agriculture Sensor Monitor (`1\_Smart\_Agriculture\_Sensor\_Monitor.cpp`)

\- \*\*Description:\*\* Simulates an IoT agricultural monitoring system utilizing classes and objects. Encapsulates soil sensor attributes (Sensor ID, moisture level, timestamp) and provides member functions to update readings and display real-time sensor metrics for crop irrigation monitoring.



\#### 2. Student Attendance Management System (`2\_Student\_Attendance\_Management\_System.cpp`)

\- \*\*Description:\*\* Demonstrates class-based encapsulation to track academic attendance. Maintains total working days and present days for each student, calculating their attendance percentage and displaying the status.



\#### 3. E-Commerce Product Catalog (`3\_E\_Commerce\_Product\_Catalog.cpp`)

\- \*\*Description:\*\* Illustrates static data members, static member functions, inline getters, and destructors. Manages product inventory items and maintains an active global count of products currently listed in the store catalog.



\#### 4. Smart Home Device Manager (`Project\_Smart\_Home\_Device\_Manager.cpp`)

\- \*\*Description:\*\* A mini-project modeling a smart home automation console. Encapsulates device states (Power ON/OFF, temperature, lock status, camera status) and manages collections of IoT devices across various rooms.
